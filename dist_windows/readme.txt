================================================================================
          ESP32-S3 LVGL 8.3 固件全自动智能烧录系统 (eFuse 硬件免选型版)
================================================================================

【智能自动识别特性 (无需用户手动选择)】
本烧录套件已集成硬件级 eFuse 自动探测技术：
1. 自动扫描连接的 ESP32-S3 串口 (CH340 / CP2102)；
2. 自动读取芯片 eFuse 底层硬件特征：
   - 探测到 8MB PSRAM  -> 自动匹配并烧录 firmware_N8R8.bin (满血 8.2MB 运存)
   - 探测到 16MB PSRAM -> 自动匹配并烧录 firmware_N8R16.bin (满血 16MB 运存)
   - 探测到 2MB PSRAM  -> 自动匹配并烧录 firmware_N8R2.bin (满血 2.0MB 运存)
3. 用户全程【零手动按键、零硬件选择】，双击脚本自动完成全流程烧录与自检！

【固件核心规格】
1. 基于 lv_micropython release/v8 官方源码编译，内核集成 LVGL 8.3。
2. 兼容 sim.lvgl.io 在线模拟器语法。
3. 内置 SPI 屏幕驱动库：ST7789、GC9A01、ILI9341 等无需额外安装驱动。
4. 内置 4路硬件 PCNT 正交编码器 (machine.Encoder)，支持 GPIO46。
5. [核心特性] 彻底关闭原生 USB-SERIAL-JTAG 控制台，GPIO19 与 GPIO20 已释放为纯粹普通 GPIO。

--------------------------------------------------------------------------------
【烧录步骤】(小白用户 10 秒上手)
--------------------------------------------------------------------------------
第 1 步：硬件连接 (极其重要！)
  - ESP32-S3 双USB开发板有两个Type-C接口：
    [接口A] 丝印通常为 "USB" (连接GPIO19/20原生USB口) -> 【不要插这个口】
    [接口B] 丝印通常为 "UART" 或靠近CH340芯片 -> 【请插这个口！】
  - 固件已将 REPL 控制台与下载通道重定向至接口B (硬件UART0: GPIO43-TX, GPIO44-RX)。

第 2 步：双击一键运行
  - Mac 用户：直接双击 "flash_oneclick_mac.command" (或终端运行 ./flash_oneclick_mac.sh)。
  - Windows 用户：直接双击 "flash_oneclick.bat"。
  - 脚本将自动识别端口与硬件型号并完成烧录，看到 "[√ 全流程自动烧录与实机校验 100% 成功！]" 即表示完成。

--------------------------------------------------------------------------------
【连接 Thonny IDE 编程】
--------------------------------------------------------------------------------
1. 打开 Thonny IDE，点击右下角解释器选择：
   -> 选择 "MicroPython (ESP32)"
   -> 端口选择开发板对应的 COM 号 / 串口号 (波特率默认 115200)。
2. 底部控制台出现 ">>>" 提示符，即可开始编写 Python 代码。
   输入 import gc; print(gc.mem_free()) 即可验证可用大运存。

--------------------------------------------------------------------------------
【常见问题与排错】
--------------------------------------------------------------------------------
Q1: 烧录提示 "Failed to connect to ESP32-S3" 怎么办？
A: 按住开发板上的 [BOOT] 按键不放，点按一下 [RST/RESET] 按键，然后松开 [BOOT] 按键，
   使芯片强制进入 ROM 下载模式，再次双击运行烧录脚本即可。

Q2: 为什么插上接口A (USB口) 电脑没有任何反应或提示未知设备？
A: 这是正常现象。因为该固件已关闭 USB-SERIAL-JTAG 硬件外设，以便将引脚彻底释放给用户作为普通 GPIO 使用。以后的代码上传、调试请全部使用接口B (UART口)。

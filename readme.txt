================================================================================
          ESP32-S3 LVGL 8.3 固件一键烧录与使用说明 (GPIO19/20 释放版)
================================================================================

【固件特性】
1. 基于 lv_micropython release/v8 官方源码编译，内核集成 LVGL 8.3。
2. 兼容 sim.lvgl.io 在线模拟器语法。
3. 内置 SPI 屏幕驱动库：ST7789、GC9A01、ILI9341 等无需额外安装驱动。
4. [核心特性] 彻底关闭原生 USB-SERIAL-JTAG 控制台，GPIO19 与 GPIO20 已释放为纯粹的普通 GPIO，不再受 USB 硬件占用。

--------------------------------------------------------------------------------
【烧录步骤】(Windows 用户免安装 Python)
--------------------------------------------------------------------------------
第 1 步：安装串口驱动 (仅首次需要)
  - 如果插入开发板后设备管理器显示黄色感叹号，请打开 drivers 文件夹安装对应驱动
    (通常为 CH341SER.EXE 或 CP210x 驱动)。

第 2 步：硬件连接 (极其重要！)
  - ESP32-S3 双USB开发板有两个Type-C接口：
    [接口A] 丝印通常为 "USB" (内部连接GPIO19/20原生USB口) -> 【不要插这个口】
    [接口B] 丝印通常为 "UART" 或靠近CH340/CP2102芯片 -> 【请插这个口！】
  - 固件已将 REPL 控制台与下载通道重定向至接口B (硬件UART0: GPIO43-TX, GPIO44-RX)。

第 3 步：确认端口号
  - 打开 Windows "设备管理器" -> 展开 "端口 (COM 和 LPT)"，查看接口B识别出的COM号 (例如 COM3)。

第 4 步：一键烧录
  - 双击运行 "flash_oneclick.bat"。
  - 窗口打开后，若默认COM号正确，直接按回车开始烧录；
    若不正确，输入正确的端口名(如 COM4)后按回车，程序将自动完成烧录并复位。
  - 看到提示 "[√ 烧录成功！]" 即表示完成。

--------------------------------------------------------------------------------
【连接 Thonny IDE 编程】
--------------------------------------------------------------------------------
1. 打开 Thonny IDE，点击右下角解释器选择：
   -> 选择 "MicroPython (ESP32)"
   -> 端口选择接口B对应的 COM 号 (例如 COM3，波特率默认 115200)。
2. 底部控制台出现 ">>>" 提示符，即可开始编写 Python 代码。

--------------------------------------------------------------------------------
【常见问题与排错】
--------------------------------------------------------------------------------
Q1: 烧录脚本提示 "Failed to connect to ESP32-S3" 怎么办？
A: 按住开发板上的 [BOOT] 按键不放，点按一下 [RST/RESET] 按键，然后松开 [BOOT] 按键，
   使芯片强制进入 ROM 下载模式，再次双击运行烧录脚本即可。

Q2: 为什么插上接口A (USB口) 电脑没有任何反应或提示未知设备？
A: 这是正常现象。因为该固件已关闭 USB-SERIAL-JTAG 硬件外设，以便将引脚彻底释放给用户作为普通 GPIO 使用。以后的代码上传、调试请全部使用接口B (UART口)。
